# ❄️ DeepSeek Snowfall

Простое и красивое расширение для браузера, которое добавляет падающий снег на страницу [chat.deepseek.com](https://chat.deepseek.com).

## ✨ Особенности

- Легкий снегопад из 120 снежинок
- Не мешает общению и не тормозит интерфейс
- Работает в Google Chrome, Яндекс.Браузере, Edge, Opera
- Не собирает данные, не требует разрешений

## 🚀 Установка

### Способ 1: ручная (для всех браузеров)
1. Скачай ZIP-архив этого репозитория и распакуй
2. Открой `chrome://extensions/` (или `browser://extensions/`)
3. Включи **Режим разработчика**
4. Нажми **Загрузить распакованное расширение** и выбери папку

### Способ 2: из Chrome Web Store (скоро)

## 🔧 Технические детали

Расширение внедряет canvas-слой поверх страницы DeepSeek, не изменяя DOM и не перехватывая данные. Полностью безопасно.

## ⚠️ Дисклеймер

Расширение неофициальное, не связано с DeepSeek. Может перестать работать при обновлении сайта.
