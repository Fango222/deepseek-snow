# ❄️ DeepSeek Snowfall

Lightweight browser extension that adds gentle snow to [chat.deepseek.com](https://chat.deepseek.com).

## Features
- 120 snowflakes
- No interference with chatting
- Works on Chrome, Edge, Yandex Browser

## Installation
1. Download ZIP and unzip
2. Open `chrome://extensions/`
3. Enable **Developer mode**
4. Click **Load unpacked** and select folder
